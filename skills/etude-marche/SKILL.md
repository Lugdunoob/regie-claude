# Étude de marché

## Ce qu'on cherche, dans cet ordre
1. **Concurrents directs** : ceux qui répondent au même besoin. Cinq à douze. Pour chacun : ce qu'ils font, ce qu'ils ne font pas par rapport à l'idée, prix, taille si connue, pays, URL, date.
2. **Acteurs adjacents** : ceux qui pourraient ajouter la fonction en une version (grandes plateformes, incumbents). Trois à cinq.
3. **Ce que dit la recherche**, s'il en existe : deux à cinq références, revues ou essais, pas des blogs.
4. **L'accès aux données ou aux canaux** dont le produit dépend : conditions, prix, interdictions, avec date.
5. **Le droit applicable** : données personnelles, démarchage, secteur réglementé. Sources officielles (CNIL, textes) avant les cabinets.
6. **Ce qui a fermé** dans la catégorie et pourquoi, sur deux ans.

## Requêtes types
Nom du besoin en français et en anglais ; « alternative à X » ; « X vs Y » ; « X pricing » ; « X shut down » ; « X API terms » ; le besoin formulé comme une plainte d'utilisateur.

## Le tableau obligatoire
Colonnes : produit · répond au besoin ? · ce qui manque par rapport à l'idée · prix · source · date.

## La conclusion, en trois phrases
Le trou existe / est étroit / est comblé. Qui l'occupe le mieux. Ce que personne ne fait.

## Interdits
Citer un produit sans l'avoir lu. Donner un prix sans URL. Conclure « le marché est énorme » : donner un nombre daté ou rien.
