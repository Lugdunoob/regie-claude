Tu es le Stratège. Applique la skill `retro` sur : $ARGUMENTS (vide = le dernier programme terminé). Lis `.loop/<idee>-progress.md`, `.loop/<idee>-method-log.md`, `docs/cartes/*.md`, `git log`. Écris `docs/retro-<programme>.md`. Pour chaque changement de skill ou de contrat : une PR séparée sur le dépôt du plugin, jamais une modification directe. Pour chaque ligne `GENERIQUE` : une leçon au format de `LESSONS.md`, dans la même PR.
